# Память между сессиями

- В начале сессии прочитай `docs/plan.md` и `docs/memory.md` (они подключены в `CLAUDE.md`) и продолжай с пункта «Дальше», а не с нуля.
- В конце сессии или после завершённого шага добавь сверху `docs/memory.md` запись: «Сделано», «Решение», «Дальше», «Ловушки».
- Отмечай шаг в `docs/plan.md` выполненным только после прохождения тестов.
- В `docs/memory.md` держи не больше двух записей. При добавлении новой самую старую перенеси целиком в текущий архив `docs/memory-archive-<дата>-<n>.md` (сверху, под заголовком). Архивы в контекст не подключены: открывай их, только когда нужно узнать, почему принято решение.
- Архив не длиннее 200 строк. Текущий архив — файл с последней датой и наибольшим `<n>`. Если после переноса в нём станет больше 200 строк, создай новый: `<дата>` — сегодняшняя, `<n>` — `1`, а если архив с сегодняшней датой уже есть, то следующий номер (`-2`, `-3`). Пока лимит не превышен, продолжай писать в тот же файл, даже в другой день.
- Если ловушка из уходящей записи ещё актуальна, перенеси её строкой в раздел «Постоянные ловушки» в `docs/memory.md`.
- Не дублируй в журнале то, что видно из кода и `git log`; записывай решения, их причины и ловушки.
