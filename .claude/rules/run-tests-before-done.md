# Юнит-тесты перед завершением фичи

Перед тем как завершить работу над фичей, запусти юнит-тесты проекта (команда указана в `AGENTS.md`, раздел «Команды»).

- Не называй фичу готовой, пока тесты не прошли.
- Если тесты падают, сначала исправь причину, затем запусти снова.
- Если тесты не удалось запустить или их ещё нет, скажи об этом прямо, не заявляй, что всё проверено.
