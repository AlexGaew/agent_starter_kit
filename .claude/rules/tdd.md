# Разработка по TDD

Код пишется по циклу red → green → refactor.

1. Red: сначала напиши тест, который описывает ожидаемое поведение, и запусти его. Убедись, что он падает по ожидаемой причине.
2. Green: напиши минимальный код, чтобы тест прошёл.
3. Refactor: улучши код, не меняя поведения, и снова запусти тесты.

- Не пиши production-код, для которого нет падающего теста.
- Один тест за раз, небольшими шагами.
- Не ослабляй и не удаляй тест, чтобы он прошёл: исправляй код.
- Исправление бага начинай с теста, который воспроизводит баг.
